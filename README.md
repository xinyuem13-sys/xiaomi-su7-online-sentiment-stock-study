# 网络舆情视角下小米 SU7 上市对公司股票收益率及换手率的影响

本仓库整理了本科生项目的论文、实证分析数据与代码，以及三平台网络评论的爬取、清洗和情感分析材料。

## 仓库结构

- `论文/`：匿名稿、完整稿及项目资料目录中的论文版本。
- `实证分析/`：Stata 数据与代码、Excel 数据及回归结果。
- `爬虫与情感分析/`：小红书、微博和抖音评论爬虫，数据清洗、朴素贝叶斯情感分析代码、模型及结果数据。

## 安全说明

原始爬虫代码中曾包含登录 Cookie。GitHub 版本已移除这些凭据，改为从以下环境变量读取：

- `XHS_COOKIES_JSON`：小红书 Cookie 的 JSON 对象字符串
- `WEIBO_COOKIE`：微博完整 Cookie 字符串
- `DOUYIN_COOKIE`：抖音完整 Cookie 字符串

请勿将真实 Cookie、Token、密码或其他账号凭据提交到仓库。

## 数据说明

评论数据来自公开网络平台，包含用户名、用户 ID、头像链接与 IP 属地等字段，仅供学术研究使用。请遵守平台规则及适用的数据保护要求，不要将数据用于识别、联系或画像个人。
